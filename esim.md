
# Overview

eSIM is the primary Yesim product. A digital SIM profile installed on a compatible device — no physical card, no carrier store visit. The user purchases a plan, scans a QR code or installs via app, and has mobile data ready before landing.

# Plan Types

| Type | Description |
|---|---|
| Local / country plan | Data in one specific country |
| Regional plan | Data across a region (Europe, Asia Pacific, etc.) |
| Global plan | Worldwide coverage — Global Package, Global Plus Package |
| Unlimited / Day Pass | Unlimited data per day; buy a pack, use days individually |
| Pay & Fly | Unlimited data plan, global coverage, Pay As You Go |

# Key Differentiators vs Competitors

- Virtual Number bundled as separate product — Airalo and Holafly do not offer this
- Hotspot (tethering) supported on most plans including unlimited
- Daily flat-rate pricing — useful for short trips
- No contracts, prepaid only, no auto-renew unless explicitly enabled
- No hidden roaming fees

# What eSIM Does NOT Include

- Phone number — data-only eSIM has no phone number
- Calls or SMS via eSIM — VoIP and messenger calls only (WhatsApp, Telegram)
- For real calls/SMS: see [Virtual Number](/concepts/products/virtual-number.md)

# Device Compatibility

Works on any eSIM-compatible device. Key models:
- iPhone XS and later
- Samsung Galaxy S20 and later
- Google Pixel 3 and later
- Most recent iPads

Device must be unlocked (not carrier-locked). Check full list: https://yesim.app/compatible-devices/

# 5G Support

Yes — where the local carrier and device support it. No separate plan required.

# Fair Use Policy (Unlimited Plans)

Speeds may be reduced after a daily or monthly threshold. Exact cap depends on the specific plan and country. No hard cutoff — throttled, not blocked.
