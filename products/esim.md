# Yesim eSIM mobile data

Yesim offers digital eSIM profiles and mobile-data plans for supported devices and destinations. The profile, the data plan and an optional separate communication product are distinct entities.

Data-only plans do not supply a phone number or traditional cellular calls/SMS. Internet-based messengers use data and their own accounts. A [Virtual Number](virtual-number.md) has its own service conditions.

| Product type | Description |
|---|---|
| Country package | Selected country, allowance and validity |
| Regional/global package | Selected set of destinations, allowance and validity |
| Unlimited package | Selected unlimited-data conditions, including any fair-use limits |
| Pay & Fly | [Data-consumption billing](pay-and-fly-esim.md) |
| Unlim Day Pass | [Annual prepaid pack of plan days](unlim-day-pass.md) |

## Before purchase

Check exact device model, regional variant, carrier lock, selected plan coverage, activation trigger, allowance, validity, hotspot and fair-use conditions. The brand's overall coverage is not an individual plan's coverage. Do not infer that every newer model supports eSIM or that 5G is guaranteed.

Installation of the eSIM profile and starting the plan's validity are separate actions. Follow current installation instructions and the selected plan's Product Description. Installation also matters for refund eligibility.
