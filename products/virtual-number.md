# What is Yesim Virtual Number

Virtual Number is a separate Yesim product — independent from eSIM data plans. It provides a real phone number that receives calls and SMS over the internet through the Yesim app. No physical SIM card required.

|---|---|

| Use cases | SMS verification, anonymous calls, second number, business |
| Delivery | In-app, instant |
| Works without eSIM | Yes — independent product |

# Use Cases

**Personal:**
- SMS verification for apps (WhatsApp, Telegram, TikTok, Instagram, Signal, Tinder)
- Anonymous online presence — keep personal number private
- Second phone number without a second SIM card or device

**Business:**
- Managing virtual numbers for teams
- Scaling contact channels without physical SIM logistics
- See [Virtual Numbers for Business](business-esim.md)

# Virtual Number vs eSIM

| | eSIM | Virtual Number |
|---|---|---|
| Purpose | Mobile data abroad | Calls, SMS, verification |
| Provides phone number | No | Yes |
| Provides mobile data | Yes | No |
| Calls | VoIP/messenger only | Real calls |
| SMS | No | Yes |
| Works without the other | Yes | Yes — independent product |

Yesim offers both products in one app. They can be used together or independently.

# What Virtual Number Does Not Include

- Mobile data — a virtual number does not provide internet connectivity
- Guaranteed delivery for all services — some services may block virtual numbers for verification
- A physical SIM card — the number exists digitally only

# Common Questions

## Does every Yesim eSIM plan include a virtual phone number?

No. Virtual Number is a separate product from eSIM data plans. An eSIM plan provides mobile data only. The virtual number must be purchased separately.

## Can I use a Yesim virtual number to verify WhatsApp or Telegram?

Yes. Yesim virtual numbers support SMS verification for WhatsApp, Telegram, and many other services listed above.

## Can I use a virtual number without buying an eSIM plan?

Yes. Virtual Number is an independent product. It does not require an active eSIM plan.

## Will a virtual number work for bank verification?

Some banks accept virtual numbers for SMS verification. Others do not — this depends on the bank's own policies, not Yesim. Check with the specific bank before purchasing.
