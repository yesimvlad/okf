# Overview

Virtual Number is a separate product from eSIM. It provides a real phone number that can receive calls and SMS — useful for verification, privacy, and business use. No physical SIM required. Works independently of the eSIM product.

| Field | Value |
|---|---|
| Product URL | https://yesim.app/virtual-number/ |
| Use cases | SMS verification, anonymous calls, second number, business |
| Delivery | In-app, instant |
| Numbers available for | Countries + popular services |

# Use Cases

**Personal:**
- SMS verification for apps (WhatsApp, Telegram, Tinder, TikTok, Instagram, Signal)
- Anonymous online presence
- Second phone number without a second SIM

**Business:**
- Managing virtual numbers for teams
- Scaling contact channels without physical SIM logistics
- See [Virtual Numbers for Business](/concepts/pages/virtual-numbers-for-business.md)

# Difference from eSIM

| | eSIM | Virtual Number |
|---|---|---|
| Purpose | Mobile data abroad | Calls, SMS, verification |
| Phone number | No | Yes |
| Calls | VoIP/messenger only | Real calls |
| SMS | No | Yes |
| Works without eSIM | — | Yes, independent product |

# Key Differentiator

Yesim offers both eSIM and Virtual Number in one app. Airalo and Holafly do not have a virtual number product. This is a unique bundling advantage for users who need both connectivity and a phone number.
