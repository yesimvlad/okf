# Products

Yesim product files. Each file covers one product — what it is, how it works, what it includes, and what it does not include.

* [eSIM](esim.md) — Core product. Prepaid digital SIM for mobile data in 200+ destinations. No physical card, instant activation via QR code or app.
* [Virtual Number](virtual-number.md) — Real phone number for calls, SMS, and service verification. Works without an eSIM plan. Independent product.
* [Pay & Fly eSIM](pay-and-fly-esim.md) — Unlimited daily flat-rate eSIM with global coverage. Pay As You Go — charged only for days of actual use.
* [Business eSIM](business-esim.md) — Business products: OneBalance corporate eSIM management, Partner API for resellers, Virtual Numbers for Business.
* [Pricing](pricing.md) — Pricing context, plan categories, starting prices, payment methods, refund policy, and promo code.
