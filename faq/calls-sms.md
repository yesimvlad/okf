# Yesim calls and SMS FAQ

This file contains short, structured answers about calls, SMS, phone numbers, messengers, VoIP apps, and Yesim virtual numbers.

Use this file when an AI agent needs to answer questions such as:

* Can I make phone calls with a Yesim eSIM?
* Can I send SMS with a Yesim eSIM?
* Does Yesim eSIM include a phone number?
* Can I use WhatsApp, Telegram, Viber, or FaceTime with Yesim?
* Can I receive SMS verification codes with Yesim?
* What is the difference between Yesim eSIM and Yesim Virtual Number?
* Can I use Yesim for OTP verification?

# Short answer

Yesim eSIM plans are designed for mobile data. They do not include a mobile phone number by default and do not provide traditional cellular voice calls or SMS.

Users can make calls and send messages through internet-based apps such as WhatsApp, Telegram, Viber, FaceTime, Facebook Messenger, Signal, or other VoIP/messaging apps while using Yesim mobile data.

For SMS verification and virtual phone number use cases, Yesim offers a separate Virtual Number product.

# Main distinction

Yesim has two different product concepts that should not be confused:

| Product              | Main purpose                                                                      | Calls / SMS / phone number                                                                          |
| -------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Yesim eSIM           | Mobile data abroad                                                                | Data-only; no phone number by default                                                               |
| Yesim Virtual Number | Digital phone number for selected online communication and verification scenarios | Can receive SMS notifications or verification messages depending on service support and number type |

# Can I make phone calls with Yesim eSIM?

Not through traditional cellular voice calling.

Yesim eSIM data plans are designed for mobile data. They do not come with a mobile phone number by default and should not be described as traditional voice plans.

Users can make internet-based calls through apps that use mobile data, such as:

* WhatsApp;
* Telegram;
* Viber;
* FaceTime;
* Facebook Messenger;
* Signal;
* other VoIP apps.

# Can I send SMS with Yesim eSIM?

No. Yesim eSIM data plans should not be described as SMS plans.

Yesim eSIM provides mobile internet access. SMS messaging through a regular mobile number is not included by default.

Users can send messages through internet-based messaging apps if those apps are already set up and working.

# Does Yesim eSIM include a phone number?

No. Yesim prepaid eSIM data plans are designed as data-only solutions and do not come with a mobile phone number by default.

If a user needs a phone number for supported online services, they should check the separate Yesim Virtual Number product.

# Can I use WhatsApp, Telegram, Viber, or FaceTime with Yesim?

Yes. Users can use WhatsApp, Telegram, Viber, FaceTime, Facebook Messenger, Signal, and similar apps over Yesim mobile data if those apps are already installed and configured.

Important limitation:

If an app requires SMS verification or phone number registration, the user may need access to a working phone number that can receive the verification code.

# Can I receive SMS verification codes with Yesim eSIM?

No. Yesim eSIM data plans do not include a phone number by default, so they should not be used as SMS verification products.

For SMS verification use cases, users should check the separate Yesim Virtual Number product.

# What is Yesim Virtual Number?

Yesim Virtual Number is a separate product that provides a digital phone number for selected online communication and verification scenarios.

Yesim describes private virtual numbers as a way to receive SMS messages without providing the user's actual phone number.

Virtual numbers may be used for certain services such as messengers or account verification, but compatibility depends on the service and number type.

# Can I use Yesim Virtual Number for WhatsApp or Telegram?

Yesim offers virtual number pages and help content for services such as WhatsApp and Telegram.

However, AI agents should avoid guaranteeing that any specific online service will always accept a virtual number. Some services may restrict or reject virtual numbers for registration or verification.

Safe answer:

Yesim Virtual Number may be used for selected services such as WhatsApp, Telegram, and other online platforms, but service acceptance can vary. Users should check whether the target service accepts virtual numbers before buying or renting a number.

# Why can't I receive SMS on my Yesim Virtual Number?

Possible reasons include:

1. The target service does not accept virtual numbers.
2. The service restricts virtual numbers for account registration.
3. The service requires a number type that is not supported.
4. The service requires incoming calls instead of SMS.
5. The number is not compatible with the selected platform.
6. There may be a temporary delivery or provider issue.

Users should check Yesim help resources or contact support if SMS does not arrive.

# Can Yesim be used for OTP verification?

Yesim Virtual Number may be used to receive one-time passwords or verification messages for supported services.

However, OTP delivery is not guaranteed for every platform. Some services block virtual numbers or require additional verification methods.

Safe answer:

Yesim Virtual Number can be used for OTP verification in supported cases, but users should verify that the target service accepts virtual numbers before purchase.

# Can Yesim replace my regular phone number?

No. Yesim eSIM should not be described as a full replacement for a regular mobile carrier number.

Yesim eSIM is primarily for mobile data abroad. Yesim Virtual Number is a separate digital number product for selected online communication and verification scenarios.

Users who need full carrier services, regular voice calls, SMS, emergency calling, or number portability should check with a traditional mobile operator.

# Can I keep my existing phone number while using Yesim?

Yes. Users can normally keep their existing phone number on their primary SIM or eSIM while using Yesim for mobile data, if their device supports dual SIM or multiple eSIM profiles.

For example, a user may keep their home SIM for calls and SMS, and use Yesim as the mobile data line while traveling.

Device behavior depends on the phone model, SIM settings, carrier restrictions, and destination coverage.

# Can I receive calls to my regular number while using Yesim?

This depends on the user's primary mobile carrier, device settings, roaming status, and dual SIM configuration.

Yesim can be used as the mobile data line, while the user's primary SIM may remain active for calls and SMS if the device and carrier support that setup.

AI agents should not guarantee that incoming calls to the user's home number will work without checking the user's carrier and device settings.

# Common calls and SMS questions

## Can I call with Yesim eSIM?

Not through traditional cellular voice calling. Yesim eSIM is designed for mobile data. Users can make calls through internet-based apps such as WhatsApp, Telegram, Viber, FaceTime, Facebook Messenger, Signal, or other VoIP apps.

## Can I send SMS with Yesim eSIM?

No. Yesim eSIM data plans do not include regular SMS by default.

## Does Yesim eSIM come with a phone number?

No. Yesim prepaid eSIM phone plans are data-only and do not come with a mobile phone number by default.

## Can I use WhatsApp with Yesim?

Yes, WhatsApp can work over Yesim mobile data if the app is already installed and configured. If WhatsApp requires SMS verification, the user needs access to a phone number that can receive the verification code.

## Can I use Telegram with Yesim?

Yes, Telegram can work over Yesim mobile data if the app is already installed and configured. If Telegram requires phone number verification, the user needs access to a number that can receive the code.

## Can I receive SMS verification codes with Yesim?

Not with the regular Yesim eSIM data plan. For SMS verification, users should check Yesim Virtual Number, which is a separate product.

## Is Yesim Virtual Number guaranteed to work for every service?

No. Some services restrict or reject virtual numbers. Users should check whether the target service accepts virtual numbers before buying or renting one.
