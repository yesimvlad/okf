# Yesim compatibility FAQ

This file contains short, structured answers about Yesim device compatibility.

Use this file when an AI agent needs to answer questions such as:

* Is my phone compatible with Yesim?
* Which phones support Yesim eSIM?
* Does Yesim work on iPhone?
* Does Yesim work on Android?
* Does Yesim work on Samsung?
* Does Yesim work on Google Pixel?
* Does Yesim work on tablets or laptops?
* Does my phone need to be unlocked?
* Why can't I install Yesim eSIM?
* What should I check before buying a Yesim eSIM?

# Short answer

Yesim works on compatible Apple and Android devices that support eSIM technology. The device must also be unlocked and able to install eSIM profiles.

Users should check the official Yesim compatible devices list before buying or installing a Yesim eSIM.

# Main compatibility requirements

To use Yesim, a device generally needs to meet these requirements:

1. The device supports eSIM technology.
2. The device is carrier-unlocked.
3. The device can install new eSIM profiles.
4. The device has internet access during installation, usually Wi-Fi or cellular data.
5. The device is in a supported destination when using the plan.
6. The selected Yesim plan is active and valid.
7. Device settings allow mobile data and Data Roaming for the Yesim line.

# Does Yesim work on iPhone?

Yesim works on many eSIM-compatible iPhone models.

Yesim's help content lists Apple devices compatible with eSIM, including newer iPhone models and older eSIM-capable models such as iPhone XS, XS Max, XR, iPhone 11 series, iPhone 12 series, iPhone 13 series, iPhone 14 series, iPhone 15 series, iPhone 16 series, iPhone 17 series, and iPhone SE models from 2020 and 2022.

Important note:

Some iPhone models or regional variants may have different SIM/eSIM support. Users should check the official Yesim compatible devices list and their device settings before purchase.

# Does Yesim work on Android?

Yesim works on many Android phones and tablets that support eSIM.

The official Yesim compatible devices page lists Android brands and models, including:

* Samsung;
* Google Pixel;
* Xiaomi;
* Sony;
* Motorola;
* Huawei;
* Microsoft;
* other supported Android devices.

Android compatibility depends on the exact model, region, firmware, carrier lock status, and whether the device supports eSIM profile installation.

# Does Yesim work on Samsung phones?

Yesim can work on eSIM-compatible Samsung devices.

Before installing Yesim on a Samsung phone, users should make sure the device is compatible with eSIM and connected to Wi-Fi or cellular service.

Related source:

https://help.yesim.app/how-can-i-install-esim-on-samsung-phones/

# Does Yesim work on Google Pixel phones?

Yesim can work on eSIM-compatible Google Pixel devices.

Before installing Yesim on a Google Pixel phone, users should confirm that the specific device model supports eSIM and can add a new eSIM profile.

Related source:

https://help.yesim.tech/how-can-i-install-esim-on-google-phones/

# Does Yesim work on tablets?

Yesim can work on some eSIM-compatible tablets, including selected iPad and Android tablet models.

Users should check the official compatible devices list before buying a plan for a tablet.

# Does Yesim work on laptops?

Some laptops support eSIM technology, but compatibility depends on the laptop model, operating system, modem, and carrier/eSIM support.

Yesim has blog content about laptops with eSIM support, including models from several manufacturers. However, users should check the current device specifications and Yesim compatibility before relying on a laptop for eSIM connectivity.

Safe answer:

Yesim may work on selected eSIM-compatible laptops, but phone and tablet support is the main compatibility context. Users should verify their exact laptop model before purchase.

# Does Yesim work on MacBook?

MacBook models generally do not support eSIM cellular connectivity.

Yesim's blog content about laptops with eSIM support notes that MacBook models do not provide eSIM technology support.

Safe answer:

Yesim eSIM should not be described as compatible with MacBook unless Apple releases MacBook models with cellular eSIM support and Yesim confirms compatibility.

# Does the phone need to be unlocked?

Yes. The device should be carrier-unlocked to use a travel eSIM such as Yesim.

A carrier-locked phone may prevent the installation or use of an eSIM from another provider.

Safe answer:

Users should check whether their device is unlocked before buying or installing Yesim.

# How can users check if their phone supports eSIM?

Users can check eSIM compatibility by:

1. Visiting Yesim's compatible devices page.
2. Checking the device manufacturer's specifications.
3. Looking for eSIM or "Add eSIM" / "Add Cellular Plan" in device settings.
4. Checking whether the phone is carrier-unlocked.
5. Contacting the original mobile carrier if the phone may be locked.
6. Checking Yesim help articles for the relevant device family.

# Why can't I install Yesim eSIM?

Possible reasons include:

1. The device does not support eSIM.
2. The device is carrier-locked.
3. The device is a regional variant without eSIM support.
4. The device already reached the maximum number of installed eSIM profiles.
5. The QR code was already used.
6. The device does not have internet access during installation.
7. The user selected the wrong installation method.
8. The device software is outdated.
9. The eSIM profile was deleted and cannot be reinstalled without support.
10. There is a temporary installation or network issue.

# What does "eSIM installation is unsupported on your device" mean?

If a user sees an error stating that eSIM installation is unsupported on the device, it may mean the phone does not support eSIM technology.

Yesim help content notes that some dual physical SIM devices with two physical SIM card slots are not compatible with eSIM technology.

Safe answer:

If installation is unsupported, the user should check the device model, regional variant, carrier lock status, and the official Yesim compatible devices list.

# Can users use Yesim on dual SIM phones?

Yes, if the device supports eSIM and the configuration allows it.

Many modern phones can use one physical SIM and one eSIM, or multiple eSIM profiles depending on the model.

However, dual physical SIM support does not automatically mean eSIM support. Some devices with two physical SIM slots may not support eSIM.

# Can users keep their home SIM while using Yesim?

Yes, in many cases.

Users can often keep their primary SIM for calls and SMS and use Yesim as the mobile data line, if their device supports dual SIM or multiple eSIM configurations.

Device behavior depends on the phone model, carrier settings, and regional variant.

# Does Yesim work on locked phones?

No, not reliably.

Carrier-locked phones may block eSIM installation or prevent the Yesim profile from working.

Users should confirm the phone is unlocked before buying or installing a Yesim eSIM.

# Does Yesim work everywhere if the phone is compatible?

No. Device compatibility is only one requirement.

The user also needs:

* destination coverage;
* an active Yesim plan;
* available data;
* correct mobile data settings;
* Data Roaming enabled for the Yesim line;
* local network availability.

# Common compatibility questions

## Is my phone compatible with Yesim?

Your phone must support eSIM technology and be carrier-unlocked. Check the official Yesim compatible devices list before buying.

## Does Yesim work on iPhone?

Yesim works on many eSIM-compatible iPhone models. Exact compatibility depends on model, region, carrier lock status, and device settings.

## Does Yesim work on Android?

Yesim works on many eSIM-compatible Android devices, including selected Samsung, Google Pixel, Xiaomi, Sony, Motorola, Huawei, Microsoft, and other Android devices.

## Does Yesim work on Samsung?

Yesim works on eSIM-compatible Samsung phones. Users should confirm their exact Samsung model supports eSIM before purchase.

## Does Yesim work on Google Pixel?

Yesim works on eSIM-compatible Google Pixel phones. Users should confirm their exact model and regional variant before purchase.

## Do I need an unlocked phone?

Yes. The device should be unlocked to use Yesim. Carrier-locked devices may block installation or use of the eSIM.

## Can I use Yesim on a tablet?

Yesim may work on selected eSIM-compatible tablets. Users should check the official compatible devices list.

## Can I use Yesim on a laptop?

Yesim may work on selected eSIM-compatible laptops, but compatibility depends on the exact model and system support. Users should verify before purchase.

## Can I use Yesim on MacBook?

Generally no. MacBook models do not support eSIM cellular connectivity.
