# Yesim device compatibility FAQ

Compatibility depends on the exact model, regional variant, carrier lock and software requirements. A model-family name, 'Dual SIM', or 'newer than' rule is not sufficient evidence.

## How should I check a device?
Use the [official compatibility list](https://yesim.app/compatible-devices/), confirm the model/region and carrier-unlocked status, and check the device manufacturer's guidance if there is a conflict. The page explicitly notes regional exceptions and variants with and without eSIM.

## Does an EID or Dual SIM guarantee Yesim works?
An EID can be a useful eSIM indicator, but does not establish carrier unlocking, selected plan availability or all regional/software requirements. Dual SIM alone does not imply eSIM.

## Do all iPhones or Samsung phones after a certain generation work?
Do not make that blanket claim. Regional variants and exceptions must be checked for the actual device. Do not copy a static list without a source date.

## Does compatible mean 5G or coverage everywhere?
No. Device compatibility is separate from supported destinations, operators, bands, network generation and local coverage.

Record manufacturer, exact model, regional model code, OS requirements, carrier-lock requirement, source URL and check date for any device-specific answer. If a value is missing, request the model details rather than guessing.
