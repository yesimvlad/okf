## Правила

- Для terms-of-service, refund-policy, unlim-day-pass, promocodes, payment-details и privacy-policy используются проверенные URL соответствующей языковой версии сайта.
- Для RU приоритет у yesim.tech/ru/. Все шесть указанных страниц там отвечают HTTP 200 с собственным canonical.
- Virtual Number остаётся на https://yesim.app/ru/virtual-number/: проверенный https://yesim.tech/ru/virtual-number/ отвечает HTTP 404.
- Три статьи Help Centre об активации, установке на Apple и безлимитных тарифах локализованы для RU, DE, FR, ES и IT. Эти языки перечислены в переключателе и hreflang справочного центра.
- Для остальных языков этих файлов Help Centre остаётся EN-источником. Пробные CS/JA-адреса перенаправляют на EN и не являются переводами.
- Для испанской активации используется конечный canonical https://help.yesim.tech/es/cuando-se-activa-mi-plan-de-datos-de-yesim/. Простое добавление языкового префикса не всегда даёт конечный URL.
- Глобальные служебные источники, например https://yesim.app/llms.txt, сохраняются. EN и 28 черновых файлов маршрутизации не изменялись.

## Ограничения на стороне сайта

Языковой URL не доказывает перевод тела документа. Privacy Policy на проверенных локализованных URL содержит английский основной текст. Terms содержит английский основной текст на AR, ZH-CN, ID, JA, RO, VI и yesim.tech/ru/; на yesim.app/ru/ Terms переведён. Это задача согласования переводов на основном сайте, а не основание объявлять юридические документы переведёнными в OKF. Ссылки оставлены в нужном языковом разделе и на приоритетном RU-домене.

Day Pass AR и CS при первой HTTP-проверке дали 500, при повторной — 200, собственный canonical и соответствующий язык. Это повод проверить стабильность этих страниц, а не утверждать, что они отсутствуют. Внутренние несогласованности Day Pass по количеству стран/размерам пакетов ранее выявлены и не решаются сменой ссылок.
