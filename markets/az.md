# Yesim məhsulları və istifadə qaydaları

Yesim səyahət üçün öncədən ödənilən eSIM data paketləri və ayrıca virtual nömrələr təklif edir. Saytın dili yaşayış yerini, ödəniş uyğunluğunu və ya səfərin əhatəsini müəyyən etmir. [^source-7] [^source-6]

| Məhsul | Hesablanma | Yoxlanmalı məlumat |
|---|---|---|
| Data paketi | Alınmış həcm | Əhatə və etibarlılığın başlanğıcı |
| Pay & Fly | İstifadə olunan data | İstiqamət tarifi və balans |
| Unlim Day Pass | İstifadə günləri | 24 saat və paketin bitməsi |
| Virtual Number | Ayrıca icarə və ya xidmət | Zənglər, SMS və yenilənmə |

[^source-4] [^source-5] [^source-6] [^source-7]

Unlim Day Pass alışdan 365 gün etibarlıdır. Müddət bitməzdən əvvəl yeni paket almaq istifadə olunmamış günləri yeni alışdan 365 gün üçün köçürür. [^source-5]

## Məhsul seçimi

Bütün ölkələri və tarixləri qeyd edib data ehtiyacını hesablayın. Dəqiq modeli, regional versiyanı, eSIM dəstəyini və operator kilidini yoxlayın. Paketləri, Pay & Fly və Day Pass-i cari şərtlərlə müqayisə edin; «qlobal» marşrutun hər ölkəsini təsdiqləmir. [^source-3] [^source-4] [^source-5]

## Quraşdırma və data ayarları

İnternet bağlantısı ilə iPhone, Samsung və ya Pixel təlimatına uyğun quraşdırın. Data xəttini və rouminqi seçin; əsas SIM-i və avtomatik data keçidini ayrıca yoxlayın. Etibarlılığın başlanğıcı paketdən asılıdır. [^source-13] [^source-14] [^source-15] [^source-12]

## Sürət, ədalətli istifadə və hotspot

Limitsiz data maksimum sürətə zəmanət vermir. Ədalətli istifadə paket və şəbəkədən asılıdır. Hotspot əksər paketlərdə mövcuddur, onların datasını sərf edir və yerli operator onu məhdudlaşdıra bilər. [^source-16] [^source-17]

## Ödəniş və geri qaytarma

Yekun məbləği, valyutanı və alış kanalını yoxlayın. Geri qaytarmada profil quraşdırılması data işlənməsə də aktivləşdirmə sayılır. Nömrənin yenilənməsi və kart yoxlamasının ayrıca şərtləri var. [^source-9] [^source-8]

Standart geri qaytarma müraciəti alışdan 30 təqvim günü ərzində aktivləşdirilməmiş, istifadə edilməmiş və müddəti bitməmiş məhsul üçün verilir. Təsdiqlənmiş €10 və ya daha az məbləğ yalnız Ycoins ilə qaytarılır. Baxılma 15 iş gününədək çəkir; banka əlavə vaxt lazım ola bilər. Texniki nasazlığı bir saat ərzində təsvir və ekran görüntüləri ilə bildirin. Xarici platformanın öz qaydaları tətbiq edilir. Yalnız data paketi adi zəng və SMS daxil etmir; nömrə funksiyaları xidmətdən asılıdır, üçüncü tərəfin təsdiqi təmin edilmir. Yesim şərtlərə əsasən şəxsiyyət yoxlaması istəyə bilər. [^source-8] [^source-9] [^source-7]

## Bağlantı və dəstək

Əhatəni, data xəttini və rouminqi yoxlayıb cihazı yenidən başladın. Adi həll kimi profili silməyin və QR-ı yenidən skan etməyin. İstiqaməti, sınanmış addımları və kart məlumatı olmayan ekran görüntülərini support@yesim.app ünvanına göndərin. [^source-20] [^source-11]

### eSIM köçürülə və ya silinə bilərmi?

Yeni telefonu yoxlayın və eSIM məlumatları ilə dəstəyə müraciət edin. Bütün provayderlər köçürməni dəstəkləmir. Yeni profil əvvəlki cihazdakı Yesim paketini deaktiv edir; eyni profil iki cihazda eyni anda işləmir. Köhnə QR-ın təkrar istifadəsi təmin edilmir. [^source-18] [^source-20]

### Qalıq data və müddət harada görünür?

Tətbiqin eSIM bölməsi qalıq data və günləri göstərir. Səhvi ekran görüntüsü və izahla bildirin. Telefon sayğacı paketin etibarlılıq məlumatını əvəz etmir. [^source-19]

## Biznes və kruizlər

OneBalance, Partner API və biznes nömrələrinin ayrıca şərtləri var. Liman və sahil əhatəsi açıq dənizdə bağlantıya zəmanət vermir; kruiz marşrutunu yoxlayın. [^source-21] [^source-22] [^source-23] [^source-24]
