# Global eSIM Plans at Yesim

Yesim offers global and multi-destination eSIM plans for travelers who visit multiple countries or need worldwide coverage. These plans activate on a single eSIM and work across supported destinations without switching plans.

Main global plans page: https://yesim.app/global/

# Global vs Regional vs Country Plans

| Plan type | Best for | Coverage |
|---|---|---|
| Global plan | Multi-region trips, worldwide travel | 83–200+ destinations |
| Regional plan | Single-region trips (Europe, Asia, etc.) | One region |
| Country plan | Single-country trips | One country |

For regional plans see [Regions](regions.md). For country plans see [Countries](countries.md).

# Fair Usage Policy on Global Unlimited Plans

Unlimited global plans are subject to a fair usage policy. After a daily threshold, speeds may be reduced. The connection remains active. Full speeds resume the next day. See [Fair usage policy](../concepts/fair-usage-policy.md).

# Common Questions

## Can I use one global eSIM in multiple countries on the same trip?

Yes. Global and regional plans are designed for multi-country use. The eSIM automatically connects to supported networks in each destination without requiring a plan change.

## What is the difference between Pay & Fly and Unlim Day Pass?

Pay & Fly is a Pay As You Go daily plan — the user is charged per day of use on a recurring basis. Unlim Day Pass is a prepaid day pack — the user buys a set of days upfront and activates them individually. Both offer unlimited data with fair usage policy. Check current plan pages for exact pricing and terms.

## Does the global plan include all 200+ countries?

Coverage varies by plan. Global Package and Global Plus Package cover 200+ destinations. Unlim Day Pass covers 83+ countries. Check the specific plan page for the current destination list before purchase.

## Is hotspot supported on global plans?

Hotspot is supported on Pay & Fly. Check the specific plan page for hotspot availability on other global plans. See [Hotspot](../concepts/hotspot.md).
