# Install and configure a Yesim eSIM

## Before installation

Confirm exact model, regional version, eSIM support and carrier unlock. Use an internet connection, and check the selected plan's validity trigger before installing. Purchase, profile installation and plan activation are different events.

## Choose the current device guide

| Device | Official instructions | Important scope |
|---|---|---|
| iPhone / supported Apple device | [Apple guide](https://help.yesim.tech/how-can-i-install-esim-on-apple-devices/) | App, QR and manual routes; labels vary by OS |
| Supported Samsung / Android device | [Android guide](https://help.yesim.tech/how-can-i-install-esim-on-samsung-phones/) | Screenshots use an older Samsung/Android version; do not infer support from that example |
| Supported Google Pixel | [Pixel guide](https://help.yesim.tech/how-can-i-install-esim-on-google-phones/) | Confirm exact model; steps vary with software |

Follow the app/device guide to add the profile, label it and select Yesim for mobile data. Apply the Yesim line's roaming instructions. Review home-SIM roaming and data switching separately.

Installation can affect [refund eligibility](../policies/refund-policy.md), even if no data is used. Do not delete a profile to troubleshoot by default or promise device transfer and unlimited QR reuse.
