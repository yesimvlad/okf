# Roaming and the selected data line

Using a travel eSIM does not mean roaming technology is absent. Yesim's installation instructions tell users to enable **Data Roaming for the Yesim line**. This setting lets that line use the supported partner networks; it does not by itself describe charges on another SIM.

## On a device supporting the relevant dual-SIM setup

1. Follow the device-specific guide and select Yesim for mobile data.
2. Review home-SIM data roaming and automatic data switching separately.
3. Check the home operator's conditions if keeping that line available for calls or SMS.

Do not promise zero home-operator charges merely because Yesim is installed. Do not call all travel eSIMs cheaper than every home plan: compare the actual destination, billing unit, allowance and current prices.

Roaming regulation, included home-operator allowances and local-SIM availability are outside this product snapshot. Use the relevant operator and current authoritative rules for those questions.
