# Fair usage policy

Fair-use conditions can allow speed reductions or other network-management measures on an unlimited-data plan. They must be read for the selected plan and destination; a general definition is not a Yesim plan specification.

The Yesim Turkey FAQ describes possible throttling after a daily usage limit, but the page reviewed does not establish an exact threshold, reduced speed or reset timezone for every Yesim plan.[^source-1]

| Parameter | Required evidence |
|---|---|
| High-speed allowance | Selected plan's Product Description |
| Speed after the allowance | Explicit plan-specific value, if published |
| Reset period/timezone | Explicit plan-specific rule |
| Hotspot treatment | Selected plan's tethering conditions |

Do not state a default 1–3 Mbps speed, guaranteed usability for particular apps, uninterrupted connectivity or identical rules for all products. Record missing values as unknown and ask support or the product owner.
