# What is a Fair Usage Policy

A fair usage policy (FUP) is a condition applied to unlimited mobile data plans. It allows the provider to reduce data speeds after the user reaches a defined threshold — daily or monthly — while keeping the connection active.

FUP is not a data cap. The connection is not cut off. Speeds are reduced (throttled), typically to 1–3 Mbps, which is sufficient for messaging, email, maps, and basic browsing but slower for video streaming or large file downloads.

# Why FUP Exists

Mobile networks have finite capacity. Without usage limits, a small number of high-consumption users can degrade the network experience for all users. FUP is a standard industry mechanism to balance network load while maintaining "unlimited" positioning.

FUP applies across all major mobile data providers — not only eSIM providers.

# How FUP Works on Yesim Plans

Yesim unlimited plans include a fair usage policy. The specifics depend on the plan and destination:

- A daily or monthly high-speed data threshold is defined per plan.
- After the threshold is reached, speeds are reduced for the remainder of the day or billing period.
- The next day (or next period), full speeds resume.
- The connection remains active throughout — the user is not disconnected.

For exact FUP thresholds on a specific plan, check the plan details page on the Yesim app or website before purchase.

# FUP vs Data Cap

| | Fair Usage Policy (FUP) | Data Cap |
|---|---|---|
| Connection after threshold | Active, reduced speed | Cut off or pay-per-MB |
| User experience | Slower but usable | No data available |
| Typical use case | Unlimited plans | Fixed-volume plans |

Yesim unlimited plans use FUP, not hard data caps.

# Common Questions

## Does Yesim cut off data after the FUP threshold?

No. The connection remains active. Only the speed is reduced after the threshold. The user can continue using data at reduced speeds for the remainder of the period.

## When do full speeds resume?

Full speeds typically resume at the start of the next day. For monthly plans, at the start of the next billing period. Check the specific plan terms for exact reset timing.

## Does FUP apply to all Yesim plans?

FUP applies to unlimited data plans. Fixed-volume plans (e.g. 1GB, 5GB, 10GB) have a data cap instead — once the volume is used, data stops unless topped up.

## Is FUP the same in every country?

No. FUP thresholds and throttled speeds vary by destination and plan. Check the plan details page before purchase.

## Does FUP affect hotspot use?

Hotspot data may be counted toward the FUP threshold separately from device data on some plans. Check the specific plan terms. See [Hotspot](hotspot.md).
