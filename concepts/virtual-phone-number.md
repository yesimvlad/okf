# What is a Virtual Phone Number

A virtual phone number is a real phone number that is not tied to a physical SIM card or a specific device. It works over the internet and can receive calls and SMS on any compatible device through an app.

Virtual phone numbers are used for:
- Receiving SMS verification codes from online services
- Maintaining a second phone number without a second SIM card
- Privacy — keeping a personal number separate from registrations
- Business communication — managing multiple numbers from one device

# How a Virtual Phone Number Works

1. The user purchases a virtual number from a provider.
2. A real phone number is assigned — from a supported country.
3. The number can receive calls and SMS through the provider's app.
4. Other people or services can send SMS or call this number like any regular phone number.
5. The user manages the number through the app — no physical SIM required.

# Virtual Phone Number vs eSIM

Virtual phone number and eSIM are separate products with different purposes.

| | Virtual Phone Number | Travel eSIM |
|---|---|---|
| Purpose | Calls, SMS, verification | Mobile data abroad |
| Provides phone number | Yes | No (data-only) |
| Provides mobile data | No | Yes |
| Requires compatible device | App only | eSIM-compatible device |
| Works independently | Yes | Yes |

Yesim offers both products in one app. They can be used together or independently.

# Common Use Cases

**SMS verification** — receiving a one-time code from an online service (WhatsApp, Telegram, Google, Amazon, etc.) without using a personal number. Useful for creating additional accounts, unblocking accounts, or maintaining privacy.

**Second number** — having a separate number for work, online marketplaces, dating apps, or travel without carrying a second phone or SIM card.

**Privacy** — registering for services without exposing a personal number. The virtual number acts as a buffer.

**Business** — managing customer-facing numbers, team numbers, or support lines from one device.

# What Virtual Phone Numbers Do Not Include

- Mobile data — a virtual number does not provide internet connectivity
- Outgoing SMS in all cases — depends on the provider and plan
- Guaranteed delivery for all services — some services block virtual numbers for verification
- A physical SIM card — the number exists digitally only

# Common Questions

## Is a virtual phone number a real phone number?

Yes. A virtual phone number is a real, dialable number assigned from a supported country. Other people and services can send SMS and make calls to it like any regular number. The difference is that it works over the internet through an app, not through a physical SIM card.

## Can I use a virtual number to verify WhatsApp or Telegram?

Yes. Yesim virtual numbers support SMS verification for WhatsApp, Telegram, and many other services. See the supported services list above.

## Does every Yesim eSIM plan include a virtual phone number?

No. Virtual phone number is a separate product from eSIM data plans. An eSIM plan provides mobile data only — it does not include a phone number. The virtual number must be purchased separately.

## Can I make outgoing calls with a virtual number?

This depends on the specific plan and provider. Check the Yesim virtual number product page for current capabilities: https://yesim.app/virtual-number/

## Will a virtual number work for bank verification?

Some banks accept virtual numbers for SMS verification. Others do not. This depends on the bank's own policies, not the virtual number provider. Check with the specific bank before purchasing.

## Can I keep a virtual number permanently?

Virtual numbers are typically available on a subscription or rental basis. Availability and duration depend on the specific number and plan. Check the Yesim virtual number page for current options.
