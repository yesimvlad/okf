# Choosing mobile data for a trip

Start with every destination, travel dates, exact device and expected activities. Compare the selected Yesim offer with the user's current connectivity options using actual prices and conditions.

| Need | Product route | Check before purchase |
|---|---|---|
| One destination | Country package | Allowance, validity, local coverage and activation |
| Several destinations | Regional or global package | Every country in the selected package |
| Variable data consumption | Pay & Fly | Destination rate, balance and top-up settings |
| Usage days across trips | Unlim Day Pass | 24-hour usage rule, annual expiry and rollover |
| Shared data or work | Suitable data package | Hotspot, FUP and actual data demand |
| Cruise itinerary | Cruise guidance | Ports/coastal partner coverage; no open-sea guarantee |
| Telephone verification | Separate Virtual Number | Purchased function and third-party acceptance |

Use the [official data calculator](https://yesim.app/data-calculator/) for estimates. Application settings, video quality, background downloads and shared devices can change usage. A calculator estimate is not a guaranteed consumption rate.

Profile installation, service activation and network connection are separate events. Follow [installation](../guides/installation.md), [activation](../faq/activation.md) and [roaming settings](roaming.md).
