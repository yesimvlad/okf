# eSIM profiles and data plans

An eSIM lets a supported device install a mobile-service profile digitally instead of inserting a new physical SIM. The installed profile and the purchased plan are separate: installation does not define allowance, coverage or the start of every plan's validity.

## eSIM technology versus a Yesim data-only product

eSIM is a delivery technology. It does not inherently mean data-only, a phone number, unlimited data or a local subscription. A Yesim **data-only** plan provides mobile internet; a separate [number service](../products/virtual-number.md) has its own capabilities.

| Check | Where to establish it |
|---|---|
| Device support | Exact model, regional version and carrier lock; [compatibility](../faq/compatibility.md) |
| Installation | Current app, QR or manual device instructions; [installation](../guides/installation.md) |
| Validity start | Purchased product's trigger; [activation](../faq/activation.md) |
| Data and destinations | Selected package; [coverage](../faq/coverage.md) |
| Calls and SMS | Expressly purchased functions; [calls and SMS](../faq/calls-sms.md) |

An eSIM can use partner-network roaming. The Data Roaming setting for Yesim and the home SIM's roaming charges are different questions; see [roaming](roaming.md).
