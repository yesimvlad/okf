# What is eSIM

An eSIM (embedded SIM) is a digital SIM card built into a device. Instead of inserting a physical plastic card, users install a digital SIM profile, which activates a mobile data connection on a compatible device.

eSIM is a standard developed by the GSMA (Global System for Mobile Communications Association). It is supported by most modern smartphones, tablets, and smartwatches.

# How eSIM Works

1. The user purchases a data plan from an eSIM provider.
2. The provider delivers a QR code or sends the profile directly to the app.
3. The user scans the QR code or installs the profile through the provider's app.
4. The eSIM profile activates and connects to a local network in the destination.
5. The device uses the eSIM for mobile data without removing or replacing the physical SIM.

Most devices support multiple eSIM profiles. The user can switch between profiles in device settings.

# eSIM vs Physical SIM

| | eSIM | Physical SIM |
|---|---|---|
| Installation | Digital, via QR code or app | Physical card inserted into device |
| Activation | Instant, before or after arrival | Requires local purchase or delivery |
| Multiple profiles | Yes, switchable in settings | One card per slot |
| Data plans | Prepaid, per destination | Carrier contract or local prepaid |
| Roaming | Not required — uses local network | Home carrier roaming rates apply |
| Device requirement | eSIM-compatible device | SIM card slot |

# What eSIM Is Used For

- Mobile data abroad without roaming charges from a home carrier
- Travel internet for tourists, business travelers, and digital nomads
- Short-term data plans for a specific destination
- Regional plans covering multiple countries on one eSIM
- Global plans for frequent travelers

# What eSIM Does Not Include by Default

- A phone number — most travel eSIM plans are data-only
- Voice calls over the mobile network — calls work through VoIP apps (WhatsApp, FaceTime, etc.)
- SMS — most travel eSIM plans do not include SMS

For a real phone number, a separate virtual phone number service is needed. See [Virtual phone number](virtual-phone-number.md).

# Device Compatibility

Not all devices support eSIM. Requirements:

- Device must have eSIM hardware support
- Device must be carrier-unlocked
- Operating system must be up to date

Examples of eSIM-compatible devices:
- iPhone XS and later
- Samsung Galaxy S20 and later
- Google Pixel 3 and later
- Most recent iPad models

# eSIM and Roaming

eSIM travel plans are not roaming in the traditional sense. The user's home carrier is not involved. The eSIM connects directly to a local or regional network in the destination through the eSIM provider's agreements.

This means the user pays the eSIM provider's rate, not the home carrier's international roaming rate. See [Roaming](roaming.md) for a full comparison.

# Fair Usage Policy on eSIM Plans

Unlimited eSIM plans are subject to a fair usage policy (FUP). After a daily or monthly data threshold, speeds may be reduced. The connection is not cut off, but throughput decreases. See [Fair usage policy](fair-usage-policy.md).

# Hotspot (Tethering) on eSIM

Many eSIM plans support hotspot — sharing the eSIM data connection with other devices via Wi-Fi. Hotspot availability depends on the specific plan and destination. See [Hotspot](hotspot.md).

# Common Questions

## Is eSIM safe to use?

Yes. eSIM uses the same mobile network standards as physical SIM cards. The profile is encrypted and stored securely on the device. See [Security FAQ](../faq/security.md).

## Can I use eSIM and my regular SIM at the same time?

Yes, on dual SIM devices. The physical SIM handles calls and home carrier SMS. The eSIM handles mobile data abroad. Both are active simultaneously.

## Can I reuse an eSIM after the trip?

It depends on the plan. Some eSIM profiles can be reactivated or topped up. Others are single-use. Check the specific plan terms before purchase.

## Do I need to remove my physical SIM to use eSIM?

No. On dual SIM devices, both the physical SIM and the eSIM can be active at the same time.
